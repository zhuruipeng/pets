## 与原建议适配的说明

- 当前档案编辑是底部弹层，关闭按钮与系统返回都经过退出保护；遮罩点击和拖动不会直接丢弃草稿。
- 头像原本在档案展示页单独更换并立即保存。本次增强这个现有入口，不把头像改造成编辑表单草稿，也不改变图片存储行为。
- 种类、性别使用现有分段选项，品种是自由输入；未额外新增选择器或选项库。
- 生日和年龄已存在时不再重复开发；本次保留真实月龄表达，不把未满一岁的宠物统一改成“0岁”。
