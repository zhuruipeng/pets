# 账户注销：开发与验证

开发日期：2026-11-04。客户端与服务端已实现，等待下一次出包和服务端部署；当前线上 `0.1.12+22` 安装包不包含本功能。

## 使用流程

登录后打开「我的 → 数据同步 → 注销账户」，阅读删除范围，输入 `DELETE`，点击「永久注销账户」。完成后返回设置页并进入游客状态。建议先在备份页导出需要保留的资料。

- 服务器删除当前区域的账户资料、密码哈希、所有设备令牌、验证码、独有宠物及其记录、费用、提醒、轨迹、附件、照片和历史同步快照。
- 发起注销的手机清除该账户工作集、发送队列、同步游标、照片同步许可和应用管理的媒体副本；取消提醒。其他本机账户的快照和引用文件保留。
- 自有未删除宠物存在其他有效共养成员时，操作返回明确提示且不改任何数据。先在宠物的共养管理中处理成员，再注销。
- 参与他人宠物的共养成员关系会移除，共享照护事实保留，结构化署名匿名化。同步新增匿名化快照，旧离线编辑也不能恢复已注销的署名。
- 仅注销宠物 App 的当前区域账户，不调用出岫官网或其他产品的账户删除接口。
- 相册原图、导出备份、其他设备的离线副本需自行删除。共享记录中的自由文本医疗事实或备注不被自动改写。

## 中断和重试

`DELETE /api/v1/me` 仅接受当前 Bearer 令牌和 `{"confirmation":"DELETE"}`，不接收目标账户 ID。请求不跟随 HTTP 重定向；成功响应必须明确返回 `{"ok":true}`。

数据库删除、共养墓碑、署名匿名化和照片清理队列在同一事务提交。发生数据库异常则完整回滚。所有认证写请求在取得同步写锁后验证令牌，避免排队中的旧请求在注销后重新写入。

若成功响应在网络中丢失，原令牌的哈希回执允许 24 小时内重复确认这次注销；它不能用于登录、读照片或同步。客户端在结果未确认期间保留数据与重试凭证，暂停同步、退出和换账号，并提示从注销入口联网重试。客户端本地清理事务失败也可使用同一回执重试。

手机清理完成后保留凭证 journal，防止平台密钥库删除失败或程序重启复用旧令牌。应用文件只在解析后的应用文档目录允许子目录内删除，保留其他账户引用的文件，不删除相册、用户导出文件或外部路径。失败文件保留队列，应用启动时重试。

服务器照片索引和授权先在事务中删除，文件清理失败保留队列，后续注销请求或服务启动时重试。

## 部署与备份

部署需包含完整 `server/app` 和两语言法律页面，先更新服务端，再发布客户端。没有新增环境变量；现有 `init_db()` 会幂等创建三个表：

| 表 | 保存内容 |
| --- | --- |
| `deleted_sessions` | 当前删除令牌的哈希和 24 小时有效期，不含账户资料或可登录令牌 |
| `erased_identities` | 随机用户 ID 的单向哈希，防止离线编辑恢复署名 |
| `pending_media_deletions` | 等待清理的附件 ID 和内容哈希，不提供读取授权 |

普通业务仍使用软删除；确认的账户注销是永久清除的明确例外。最少的成员删除墓碑保留随机标识和删除状态。

受限运维备份按现有周期轮换。恢复旧备份前必须保存当前删除标记及已完成的删除要求，恢复后重新清除对应账户、私有数据和照片，并恢复匿名化标记；完成检查前不得开放业务流量。不得将旧备份直接作为恢复账户数据的途径。
