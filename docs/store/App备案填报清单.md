## 一、先搞清楚一件事：你需要办几次备案？

App 备案和网站备案是**两件事**，但好消息是**可以复用**。

| | 网站 ICP 备案 | App 备案 |
|---|---|---|
| 备案对象 | 域名（`weiyuantool.com`） | App（`com.weiyuantool.pet_app`） |
| 提交入口 | 域名注册商 / 服务器厂商 | **服务器厂商或应用分发平台**（不是工信部官网） |
| 主管机关 | 山东省通信管理局 | 山东省通信管理局（按公司注册地） |
| 拿到的东西 | ICP 备案号（如 `鲁ICP备xxxxxxxx号`） | APP 备案号（如 `鲁ICP备xxxxxxxx号A1`） |

⚠️ **关键判断依据**：工信部明确规定
「**对于已履行网站备案手续的主办者，不需要重新填报主体身份信息，仅需补充 App 有关信息**」。

|---|---|

| 网站备案号 | **`鲁ICP备2026031884号-2`**（已取得，官网页脚已展示） |
| 服务器 IP | `124.223.174.129` |
| 服务器归属 | **腾讯云**（AS45090 Shenzhen Tencent Computer Systems）——已实测确认 |
| 备案省份 | 山东省（按公司注册地：临沂市罗庄区） |

→ **走「情况 B」：网站已备案，App 备案时主体信息沿用，只补 App 部分。**

📌 **备案类型选「新增服务」**：备案号带 `-2` 说明同一主体已备案过1 个服务，
现在要加第 2 个（App）。若腾讯云后台显示的已备案服务里**找不到** `weiyuantool.com`，
就改选**「接入备案」**（原备案在别家接入商，服务器已迁到腾讯云）——两种都要做，因为
**域名解析到腾讯云境内服务器就必须做接入备案**。

`/api/site-content` 接口注入的，我抓静态 HTML 只看到空占位 `icp:''`。
**教训：现代站点备案号常在异步数据里，查证要用真实浏览器渲染或直接查数据接口。**

是通用提示，与本项目无关。

### 「使用外部 SDK」⚠️ 一个都不用勾（2026-10-04 实测更正）

腾讯云「使用外部 SDK」的下拉列表是这个：
```
框架类 / 广告类 / 推送类 / 统计类 / 地图类 / 第三方登录类 /
社交类 / 支付类 / 客服类 / 测试类
```

⚠️ **列表里没有「定位类」。** 页面右侧提示：「若服务类型列表中没有您的 SDK 服务，
则无需选择」——**所以本App 这一项整个留空即可。**

**为什么不用勾定位：**

| 依赖 | 实际是什么 | 为什么不属于「第三方 SDK」 |
|---|---|---|
| `geolocator` | **Flutter 官方插件** | 调系统原生定位 API（Android Location / iOS CoreLocation），**不采集 OAID/IDFA 等设备标识符** |
| `flutter_map` | 仅海外区渲染底图 | **cn 区不渲染底图**（境内涉测绘资质），实际未使用 |
| 通知 / 密钥库 / 文件选择 / 分享 / 图表 | 纯本地能力 | 不发起网络请求 |

这个列表只管**真正接入的第三方 SDK 供应者**（高德/腾讯定位/友盟/极光推送那种），
本项目一个都没有。隐私政策第五节也已明写「不接入支付、社交、统计等第三方 SDK」。

⚠️ **别多勾。** 勾多了管局会认为隐瞒 SDK，容易被驳回；勾少了与实际不符，
商店审核阶段也会被追问。原则是「只勾真正接入的第三方 SDK」，本项目 **0 个**。

## 五、软著要不要一起办？

**软著与App 备案是两码事，但都建议做。**

- **App 备案**：法律要求的强制项，没备案商店不给上。
- **软著登记**：App 备案本身**通常不强制**，但
  - 部分应用商店（尤其应用宝）把它作为上架材料；
  - 它是 App 著作权的法律证明，维权/被抄袭时有用。

本项目的软著材料**已全部备齐**（实名认证通过就能提交）：

| 文件 | 内容 |
|---|---|
| `docs/store/软著-程序鉴别材料-源代码-V0.1.5.pdf` | 60 页，前 30 页 + 后 30 页，每页 50 行 |
| `docs/store/软著-文档鉴别材料-操作说明书-V0.1.5.pdf` | 8 页十章，配 8 张真机截图 |
| 申请表信息 | 软著申请表里要填的名称、版本、著作权人等（见 `docs/store/上架文案与提交清单.md`） |

⚠️ 软著申请周期约 30 个工作日（**登记机构审查**），建议**和备案并行提交**，
不等它下来先把 App 备案办了。

⚠️ **软著材料上的版本号是 V0.1.5，而当前 App 是 0.1.7。**
登记机构只要求材料与实际软件**大致对应**，不强制逐版更新，所以**不必重做**。
但如果后续想用软著做推广或应用宝审核，版本号对不上可能被要求补交说明。

## 七、能不能同时上苹果 App Store（中国区）？

**能，而且 iOS 比安卓省事得多。但 App 备案是两边共同的前置。**

### iOS 中国区 vs 国内安卓商店

| | 安卓（国内商店） | **iOS App Store 中国区** |
|---|---|---|
| 开发者账号 | 华为/小米/OPPO/vivo/应用宝**各注册一家** | **一个全球账号即可**，无需中国公司账号 |
| 软著 | 多数商店**必交** | **不强制**（安卓才必交） |
| 审核标准 | 各店不一，踩坑多 | Apple 统一标准，可预期 |
| 周期 | 6–12 个月（逐店过） | 提交后约 1–3 天 |
| ICP 备案号 | 必须 | **必须**（选中国大陆地区时强制填） |

### ⚠️ 关键：Apple 要的是「App 备案号」，不是网站备案号

App Store Connect 官方原文：「App 信息页面上的 ICP 编号和元数据应与
中国工业和信息化部的备案信息一致」，验证通过后会显示在产品页上。

- 现在手里的是**网站备案号** `鲁ICP备2026031884号-2`
- App 备案会拿到**独立新号**（形如 `鲁ICP备2026031884号-2A`，`A` 后缀）

👉 **正在办的这个 App 备案不只是安卓上架的前置，iOS 上架卡在同一件事上。
办了它，两边一起通。**

### 三个硬前提

1. **必须有 Mac**（硬卡点）。本机只有 Windows，没有 Xcode，iOS 包构建不出来。
   `app/ios/` 目录存在，但**从未在 Mac 上编译过** ——
   `flutter_secure_storage` 的 iOS Keychain 权限也从未在真机验证。
2. **苹果企业开发者账号**：688 元/年。需大陆营业执照 + 法人实名 + 对公信息。
   ⚠️ 个人账号（99 美元）不行—— **带注册登录的 App 必须企业账号**。
3. **iOS 版要单独构建**：i18n 双表已备好，但首次编译会有一轮调试
   （Keychain 权限、插件的 iOS 端配置）。

### 建议顺序

**先不动iOS。** 优先级：

1. **把 App 备案办下来**（正在做）→ iOS 与安卓的**共同前置**
2. 备案号到手后再考虑 Mac + 苹果账号
3. 有 Mac 后再做 iOS 首次构建

⚠️ 本App 无游戏/出版/宗教/新闻属性（宠物健康记录工具），
不需要 ISBN 出版物号或网络出版服务许可证。前置审批统一选「以上都不涉及」。
