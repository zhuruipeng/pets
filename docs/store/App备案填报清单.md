# App 备案：填报清单与操作步骤

> 依据：工信部 2023-07《关于开展移动互联网应用程序备案工作的通知》+
> 《非经营性互联网信息服务备案管理办法》第十二条。
> 整理时间：2026-10-04。本清单里的**指纹、名称、域名都是从当前 0.1.7+9 产物里读出来的真值**，
> 不需要再去别处查；软著编号等审核后才有的项留了空位。

---

## 一、先搞清楚一件事：你需要办几次备案？

App 备案和网站备案是**两件事**，但好消息是**可以复用**。

| | 网站 ICP 备案 | App 备案 |
|---|---|---|
| 备案对象 | 域名（`weiyuantool.com`） | App（`com.weiyuantool.pet_app`） |
| 提交入口 | 域名注册商 / 服务器厂商 | **服务器厂商或应用分发平台**（不是工信部官网） |
| 主管机关 | 山东省通信管理局 | 山东省通信管理局（按公司注册地） |
| 拿到的东西 | ICP 备案号（如 `鲁ICP备xxxxxxxx号`） | APP 备案号（如 `鲁ICP备xxxxxxxx号A1`） |

⚠️ **关键判断依据**：工信部明确规定
「**对于已履行网站备案手续的主办者，不需要重新填报主体身份信息，仅需补充 App 有关信息**」。

所以先确认一件事：

> **`weiyuantool.com` 的网站 ICP 备案做了没有？**

我查了官网首页，**没有找到任何ICP 备案号**（`鲁ICP备…` 一个都没有）。
这说明两种可能：

- **情况 A：网站备案还没做/没拿到号** → 建议**先做网站 ICP 备案**，拿到号后再做App 备案。
  这样 App 备案时主体信息不用重填，能省一大截时间。
- **情况 B：网站备案做过了，只是没在官网首页展示**（备案号可以挂在 footer 或单独页面，
  搜索引擎不一定抓得到）→ 直接做 App 备案，主体信息会沿用。

👉 **请老板确认：官网 weiyuantool.com / api.pet.weiyuantool.com 有没有拿到过 ICP 备案号？**
有就按情况 B 走，没有就按 A 走。

## 二、提交入口（选一个就行，别重复提交）

**推荐：走服务器厂商。** 本项目服务器在腾讯云（`124.223.174.129`），
而 App 有服务端、需要「网络接入信息」，走腾讯云备案系统最顺。

| 入口 | 网址 | 说明 |
|---|---|---|
| **腾讯云备案** | https://cloud.tencent.com/product/ba | 本项目同机，最省事，主体/域名信息可复用 |
| 华为云 / 阿里云备案 |各自官网 | 也行，但服务器不在它们那儿，可能要补说明 |
| **应用商店代报** | 开发者后台 | 华为、小米、OPPO、vivo、腾讯、应用宝都有「App 备案」入口，商店帮你初审 |
| 工信部政务服务平台 | https://beian.miit.gov.cn | **只能查询，不能提交**（很多人在这踩坑） |

⚠️ 官方口径明确：APP 主办者**通过其网络接入服务提供者或APP 分发平台**
向省级通信管理局提交，**不能自己上工信部网站提交**。

## 三、填报信息（照抄即可，已从产物核实）

### 主体信息

| 字段 | 填什么 |
|---|---|
| 主办者性质 | 企业/事业单位 |
| 主体名称 | 与营业执照**完全一致**（临沂未远工具…以执照为准） |
| 统一社会信用代码 | 营业执照上的 18 位 |
| 法定代表人 | 执照上的法人 |
| 证件 | 营业执照副本扫描件（**需加盖公章**）、法人身份证正反面 |
| 负责人/联系人 | 姓名 + 手机 + 邮箱 |

⚠️ 主体名称一个字都不能错，错了会被驳回重填（20 个工作日就没了）。

### App 信息

| 字段 | 填什么（真值） |
|---|---|
| **App 名称** | `我的宠物` |
| **版本号** | `0.1.7`（若商店按 build 填则`9`） |
| **应用包名** | `com.weiyuantool.pet_app` |
| **应用图标** | `docs/store/icon-512.png` |
| **应用简介** | 宠物健康管理与提醒工具：档案、记录、提醒、轨迹、费用与文档 |
| **下载地址** | `https://api.pet.weiyuantool.com/download/app-cn-release.apk` |
| **应用服务内容/类别** | 工具类 —— 宠物健康记录与提醒（不涉及新闻/出版/教育/影视/宗教，无需前置审批） |
| **网络接入服务商** | 腾讯云 |

> App 名称填的是**装机后图标下方显示的那个名字**，即「我的宠物」（`cn` flavor 的
> `app/android/app/src/cn/res/values/strings.xml`）。同主体下 App 名称唯一。
> ⚠️ **一旦装机显示名改了，备案也要跟着做变更。**

### 域名 / 网络资源

| 字段 | 填什么 |
|---|---|
| 服务域名 | `api.pet.weiyuantool.com`（另`www.weiyuantool.com`） |
| 域名证书 | 阿里云/腾讯云买的域名证书 |
| 备案主体与域名注册人 | **必须是同一家** —— 备案主体即公司，域名注册人也得是这家公司 |

⚠️ 这条最容易卡人：**域名注册人必须是公司，不能是个人**。如果 weiyuantool.com
的 WHOIS 注册人是个人，要先做「域名注册人变更」。

## 四、审核与后续

| 阶段 | 时限 | 谁做 |
|---|---|---|
| 接入商/平台预审 | 1–3 个工作日 | 腾讯云 / 商店 |
| 短信核验| 提交后立刻 | **老板本人**（管理员手机号，接到短信要回复确认） |
| 省通信管理局审核 | **≤20 个工作日** | 山东省通信管理局 |
| 公示 | 通过后 | 工信部系统可查 |

**拿号之后还有两件事（不做会被商店驳回）：**

1. **App 显著位置标明备案号**，并在备案号下方链接 `https://beian.miit.gov.cn`。
   —— 代码里已经预留好展示位：`core/region.dart` 的 `requiresIcpDisplay`（cn 区为 true，
   intl 区为 false），「我的」页会显示。**号到手告诉我，我改进去。**
2. **官网也要挂备案号**（网站备案的要求），现在官网没挂。

## 五、软著要不要一起办？

**软著与App 备案是两码事，但都建议做。**

- **App 备案**：法律要求的强制项，没备案商店不给上。
- **软著登记**：App 备案本身**通常不强制**，但
  - 部分应用商店（尤其应用宝）把它作为上架材料；
  - 它是 App 著作权的法律证明，维权/被抄袭时有用。

本项目的软著材料**已全部备齐**（实名认证通过就能提交）：

| 文件 | 内容 |
|---|---|
| `docs/store/软著-程序鉴别材料-源代码-V0.1.5.pdf` | 60 页，前 30 页 + 后 30 页，每页 50 行 |
| `docs/store/软著-文档鉴别材料-操作说明书-V0.1.5.pdf` | 8 页十章，配 8 张真机截图 |
| 申请表信息 | 软著申请表里要填的名称、版本、著作权人等（见 `docs/store/上架文案与提交清单.md`） |

⚠️ 软著申请周期约 30 个工作日（**登记机构审查**），建议**和备案并行提交**，
不等它下来先把 App 备案办了。

⚠️ **软著材料上的版本号是 V0.1.5，而当前 App 是 0.1.7。**
登记机构只要求材料与实际软件**大致对应**，不强制逐版更新，所以**不必重做**。
但如果后续想用软著做推广或应用宝审核，版本号对不上可能被要求补交说明。

## 六、我的建议顺序

1. **先确认 weiyuantool.com 有没有网站 ICP 备案号** ← 决定后面走A 还是 B
2. 若是情况 A：**先办网站 ICP 备案**（腾讯云，与服务器同厂商，最快）
3. 网站备案下来后，**在官网挂备案号**（这条是网站备案的硬要求，别忘）
4. **提交 App 备案**（主体信息沿用网站的，只补 App 部分）
5. 提交后**盯短信核验**（老板本人操作）
6. 拿号 → 告诉我，我回填进 App 的「我的」页展示位
7. **并行**：软著材料已齐，实名认证一通过就提交
